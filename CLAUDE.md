## Hard Rules (Non-Negotiable)

### Backend
- ✅ **JWT Authentication:** Token expire 15 minutes, auto-logout
- ✅ **Password Policy:** Min 8 chars, alphanumeric (BCrypt hashing)
- ✅ **Audit Columns:** Every table MUST have id, guid, created_at, created_by, updated_at, updated_by, deleted_at
- ✅ **Soft-delete:** Use deleted_at IS NULL, never remove data
- ✅ **No Lombok:** Write explicit getters/setters/constructors
- ✅ **No custom auth:** Portal JWT handling via PortalSsoFilter
- ✅ **Use @PreAuthorize:** For role-based access control

### Frontend
- ✅ **Angular 18 Standalone:** No NgModules
- ✅ **OnPush Change Detection:** All components
- ✅ **Angular 18 Control Flow:** @if, @for, @switch (no *ngIf, *ngFor)
- ✅ **Tailwind CSS:** No inline styles
- ✅ **AuthGuard:** Protect routes (all except /login)
- ✅ **JwtInterceptor:** Attach token to all requests
- ✅ **Auto-logout:** When token expired (15 min)

### Database
- ✅ **Flyway Migrations:** SQL files, never edit committed files
- ✅ **Vendor Split:** oracle/ + postgresql/ folders, same version numbers
- ✅ **Soft-delete Index:** Every table must have idx_{table}_deleted_at
- ✅ **Foreign Keys:** Proper naming: fk_{table}_{ref_table}
- ✅ **Timestamps:** DEFAULT NOW() or CURRENT_TIMESTAMP

## Troubleshooting

**Port 8081 already in use?**
- Change in application-local.yml

**Database connection error?**
- Verify Docker is running: `docker-compose ps`
- Check JWT_SECRET is set

**Frontend blank page?**
- Check browser console for errors
- Verify backend is running on 8081
- Clear cache

**Authentication failing?**
- Verify user exists in database
- Check JWT_SECRET matches between backend and frontend
- Review logs: `mvn ... -Dspring-boot.run.profiles=local spring-boot:run`
