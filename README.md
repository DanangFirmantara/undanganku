## Troubleshooting

**Port already in use?**
- Change port in `application-local.yml` (backend: 8081, frontend: 4200)

**PostgreSQL connection error?**
- Verify Docker is running: `docker-compose ps`
- Check logs: `docker-compose logs postgres`

**Frontend blank page?**
- Check browser console for errors
- Ensure backend is running on http://localhost:8081
- Clear cache: Ctrl+Shift+Delete

**JWT_SECRET not set?**
- Export before running: `export JWT_SECRET=your-secret`
- Or add to application-local.yml (dev only)
